# CRAFT：文案与表现手法

这份文档补的是**判断**，不是机制。机制在 [HOW_IT_WORKS.md](HOW_IT_WORKS.md)，
踩过的坑在 [DEVLOG.md](DEVLOG.md)。这里记的是三件容易被当成「凭感觉」的事：

1. 主 slogan 为什么是那一句（**选句的标准**）
2. 「炫」到底差在哪（**量化归因**，不是审美争论）
3. 一个元素画风不对，为什么整片都塌（**尾焰**）

> ⚠️ 本文引用了**极少量**歌词短句，仅用于评论与分析（合理引用）。
> 仓库其余部分不含任何歌词文本，机制见 [NOTICE.md](../NOTICE.md) §1。

## 1. 主 slogan：「今天仍在轨道上」

### 1.1 候选

从片中出现的句子里挑，四个进入决选：

| # | 句子 | 时间码 | 落点镜头 | 性质 |
|---|---|---|---|---|
| A | 今天仍在轨道上 | `269.78` | `shot_still`（full） | 事实陈述 |
| B | 我最亮的星 | `266.74` | `shot_brightest`（split, stars×240 + bloom） | 修辞 |
| C | 甩下踌躇吧 | `49.11` | `shot_letgo`（split, 火箭刚点火） | 祈使 |
| D | 因为朝阳是你也是我 | `50.80` | `shot_dawn`（**bleed**，满屏日出 7.8 s） | 抒情 |

### 1.2 判据（四条，按权重）

**① 自带时间锚点。** 一句话要能当标题，它得在**时间上成立**。
A 的「**今天**」是唯一自带锚点的——而且它每年国庆都成立，不需要观众知道 1970。

**② 事实含量 > 0。** 标题若是纯修辞，片子就成了配图散文。
A 是可查证的（2026 年仍在轨）；B、C、D 的成立与否取决于听者，不取决于记录。

**③ 有画面互证。** A 落在 `shot_still`，同帧还有一张表：

```python
("table", dict(title="2026", rows=[("status", "still in orbit"),
                                   ("2009 re-track", F.ORBIT_2009),
                                   ("re-entry", "not yet")]))
```

**她说完这句话，画面就把证据摆出来了。** 这是全片唯一「标题 + 脚注互证」的位置。

**④ ★ 歌自己完成了切换。** 这条是本鱼写这份文档时才发现的，也是最硬的一条：

```
263.21-266.74   东方红 太阳升
266.74-269.78   我最亮的星        -> shot_brightest
269.78-272.73   今天仍在轨道上    -> shot_still
```

**这两个句子在歌里是紧邻的，分界正好是 `269.78`。**
也就是说：不是我们挑了 A 而丢掉 B，是**歌本身在那一秒从「最亮」转向「仍在」**。
片子只是跟着切——`shot_brightest` 用 240 颗星和一团 bloom 把「最亮」画到极处，
下一镜**硬切**到一行 52 px 的 `bigtext`。

> 修辞的尽头是事实。这个转折是原曲给的，我们只负责不要错过它。

### 1.3 为什么没有选 C（最容易被质疑的一个）

**C 的画面契合度是全片最高的。** 客观事实：

- `shot_letgo`（49.11–50.80）= 火箭 `ignited=0.0`，**点火瞬间**
- `shot_dawn`（50.80–58.62）= `mode="bleed"` **满屏**、28 团 bloom、`her.deploy=1.0`
- 所在章节名：`02 / FIRST LIGHT`

「甩下踌躇」配点火，「朝阳是你也是我」配满屏日出，章节叫 FIRST LIGHT——
**这一组是全片文案与画面咬合最紧的地方**，比 A 紧。这点必须承认。

不选它的理由有三条，都与「当标题」有关，与「好不好」无关：

1. **结构位次。** C 是**第一组答案**（歌里问「要如何度过」，C 是第一个回应）。
   标题若取第一组答案，就把后面的工程记录变成了重复。A 在**收束段**，是终点。
2. **被工程答案接管。** C 之后，同一个问题在 `45.84` 的 `shot_drift` 里已经被
   max-Q 曲线接管（`answer(..., chart="q")`）。**同一句再当标题，会跟自己的中段打架。**
3. **主语是「你」。** C 与 D 都是对「你」说的；A 的主语是**她**（东方红一号）。
   这支片子的立场是「让记录自己说话」，标题的主语不该是观众。

**⚠️ 但换一把尺子，结论会变。** 若判据是「国庆当天的感染力」，
C/D 与 A **并列第一**——它们更热，A 更冷。
选 A 是一次**明确的取舍**：要「可信」而不是「燃」。不是 A 更好，是我们选了另一条。

### 1.4 一条自我更正

初版论证里本鱼写过「A 是收束段的**首句**」——**这是错的**。
`269.78` 这一句在 `08 / STILL IN ORBIT` 段内是**第 3 行**（前有 `东方红 太阳升`、`我最亮的星`）。

它之所以读起来像首句，是因为**前两句属于「引子」，从 A 开始才是「结论」**。
理由成立，但「首句」这个说法不成立。**论证里的事实错误要单独标出来，不能靠结论正确蒙过去。**

## 2. 「炫」的量化归因

被问过一句很准的话：*是不是没用工程技术细节填满每一帧？*

不辩论，量。参考片取 14 帧、本片取 13 帧，同一套指标：

| 指标 | 参考片 | 本片（当时） | 比值 |
|---|---|---|---|
| 平均亮度 | 19.9 | 12.1 | 0.61 |
| **墨量** `lum>38` | 10.41% | 4.53% | **0.44** |
| 亮部 `lum>120` | 2.49% | 1.29% | 0.52 |
| **高光** `lum>190` | 0.51% | **0.00%** | ~0 |
| 边缘密度 | 3.84 | 2.87 | 0.75 |
| **峰值亮度** | **242.0**（最暗帧也有 188.7） | 155.8（从不超 ~190） | 0.64 |

### 三级原因（顺序不能颠倒）

**一级：不是细节少，是「没有高光」。**
本片调色板最亮色是 `(255,176,0)`，亮度上限 **143.7**，而后期**只减不加**。
⇒ 全片结构性不可能出现高光。解法不是加内容，是加一层 `tk.hot()`（见 HOW_IT_WORKS）。

**二级：主窗装的是「象形图」，不是「图表」。**
参考片主窗是带坐标轴/网格/刻度/读数/注释的定量曲线；本片当时是 44×30 粗块象形图或三行字。

> **「工程技术细节」的真正含义是「结构化定量图表」，不是「更多日志行」。**

这条直接导致 `el_aero` 面积图的诞生（墨量 1.51% → 7.51%，见 DEVLOG §8）。

**三级：留死区。** 纯背景横带在参考片里几乎没有，每个区域都派了活。

### ⚠️ 诚实边界

东方红一号的**真实**记录比 LLM 训练日志薄得多，而且已定「不许编事实」。
所以「加细节」只能是**把她已有的真数据做成图表**：

- 56 年轨道根数与半长轴衰减（0.884 m/圈，179,934 圈）
- 20.009 MHz 下行链路、母线电压衰减、自转 120 r/min、热控 -? / +?

**不是造假遥测。** 加不出来的地方就空着，比编一条好看的数据强。

## 3. 尾焰：一个元素画风不对，整片就塌

被指「不适配」时，第一反应是「火焰本来就该是橙色的」。查完发现：

> 尾焰是全稿**唯一**用照片式火焰色 `(235,130,35) → (255,255,200)` 填的**实心色带**。

而：箭体是琥珀**线框**、星空是**点**、图表是**扫描线**、报纸是**网点**。
**全片只有这一处在用「真实世界的颜色」。**

**修法不是调色，是换语法。** 改成**琥珀扫描线**：

```python
yy += 2          # 每 2 px 一条
width = 2        # 线宽 2 px
tk.hot(0.97 - 0.58 * t)   # 喷口白热 -> 尖端暗琥珀
```

形状、收敛、裁剪逻辑**一行不改**——只换填充方式。

> **教训：风格不是“整体调性”，是“最不合群的那个元素”。**
> 一处破例，观众看到的是「这里不对」，而不是「这里特别」。

这条与 DEVLOG §7 的右栏事故是同一类：**局部正确、整体错误，而所有自动检查都是绿的。**

## 4. 让记录回答，而不是替她回答

片中有一组问句（「要如何度过」）。第一版用影片自己的隐喻作答——雾、日出、蜉蝣。

被否掉了。理由一句话：

> **应该让东方红一号本身的故事来回答，而不是我们替观众回答。**

改版后只列她自己的记录，每行都能在 `facts.py` 查到：

```
点火 / 运载 / 入轨  ·  播送 / 周期 / 静默日  ·  2009 重测轨 / 2026 仍在轨
```

这就是这支片子与「励志片」的分界：**它不靠修辞说服你，靠记录。**

## 5. 四条可迁移的标准

写别的片子也能用：

1. **标题要有时间锚点。** 「今天」「今年」「第 56 年」——让一句话在特定日期成立。
2. **标题的主语要是作品的主体，不是观众。** 「你是……令」是口号，「她仍在」是陈述。
3. **引用的句子要和它所在的画面互证。** 说不清画面的句子，不该当标题。
4. **风格问题先找“最不合群的那个元素”。** 九成不是整体不对，是一处破例。

反过来也有两条**不要**：

- 不要用「更燃」当唯一标准——燃与可信常常反向，得明说选了哪个。
- 不要在论证里混入未核实的事实（本鱼就在 §1.4 栽过一次）。
